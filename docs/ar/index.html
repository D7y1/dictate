أشِر، تكلّم، أرسِل.

جلسات مراجعة بالصوت والمؤشر للمواقع والفيديو، جاهزة لـ Claude.

حمّله من GitHub طريقة البدء
PAGE·/what-it-does

أشِر مرة واحدة، ويعرف Claude الموضع بالضبط.

يسجّل Dictate كلامك وما تشير إليه معًا، ثم يربط كل جملة بعنصرها أو إطارها أو توقيتها. وكلمات مثل «هذا» و«هنا» تعود إلى حيث كان مؤشرك لحظة نطقها.

يثبّت العنصر الذي تحت مؤشرك

في موقعك، تثبّت إضافة Dictate لمتصفح Chrome ما تشير إليه وتلتقط صورة للشاشة. يصل إلى Claude رابط الصفحة ومحدِّد العنصر ونصه وشيفرة HTML، فتعني عبارة «هذا الزر» زرًا واحدًا بعينه.

T للكلام · AltA تثبيت بلا كلام

يضع ملاحظات الفيديو على إطارها الدقيق

انقر الصورة لتثبيت نقطة، واسحب لرسم مربع حول جزء منها، واضغط I ثم O لتحديد مقطع. كل ملاحظة تحمل توقيتها وموضع إشارتك على الإطار، ويتوقف الفيديو وأنت تتكلم.

IO مقطع · M علامة · ←→ إطار واحد

يفرّغ كلامك بالعربية والإنجليزية على GPU جهازك

يعمل Whisper على جهازك ويحوّل صوتك إلى نص موقّت كلمةً كلمة، حتى لو تنقّلت الجملة الواحدة بين لغتين. وقبل الإرسال تصحّح ما أخطأ في سماعه، وتستبعد الملاحظات التي لا تريدها.

يسلّم Claude Code تقريرًا مربوطًا بالمواضع

أرسِل الجلسة فيقرأ Claude كل ملاحظة مع موضعها وصورها. يرد بخطة مرقّمة لما فهمه، ثم ينفّذ التعديلات، ولا يتوقف ليسألك إلا إذا كانت الملاحظة غامضة فعلًا.

PAGE·/start

ثبّته مرة واحدة، ثم اكتب /dictate.

تحتاج إلى Node 20 أو أحدث، ومتصفح Chrome أو Edge. لا حاجة إلى تنزيل الكود: تشغّل المهارة أحدث نسخة من Dictate من npm في كل مرة، فتصلك التحديثات في مراجعتك التالية.

  1. 1

    أضف المهارة

    يثبّت /dictate في Claude Code من skills.sh، ويبقيها الأمر npx skills update محدّثة.

    npx skills add D7y1/dictate -g
  2. 2

    جهّز تحويل الكلام إلى نص

    يثبّت faster-whisper (مع مكتبات CUDA إن كانت بطاقتك من NVIDIA)، وينزّل نموذج الكلام. يستغرق بضع دقائق في المرة الأولى، ويمكنك تشغيله مرة أخرى بأمان. وإن تخطّيته، يعتمد Dictate على التعرّف على الكلام المدمج في المتصفح.

    npx @d7y/dictate setup
  3. 3

    ثبّت الإضافة، مرة واحدة

    لمراجعة المواقع فقط، ولا يسمح Chrome إلا لك بتنفيذ هذه الخطوة. يفتح لك الإعداد والاستوديو صفحة تثبيتها، ثم يتأكدان من أنها تعمل.

  4. 4

    اكتب /dictate في Claude Code

    في أي مشروع. اذكر ما تراجعه، أو أعطه ملف فيديو. يفتح Claude الاستوديو وينتظر، ثم يبدأ العمل حين تضغط «إرسال».

    /dictate صفحات التسجيل
/dictate C:\footage\ep12.mp4
  • Node 20+
  • Chrome أو Edge
  • Python 3.9+ يشغّل Whisper، ويُنصح به
  • بطاقة NVIDIA اختيارية، والمعالج يكفي لكنه أبطأ

PAGE·/stack

خمسة أجزاء، ولا خطوة بناء.

الخادم والاستوديو ونموذج Whisper تعمل كلها على جهازك. والاستوديو ملفات عادية، فيعمل فورًا ولا شيء فيه يتعطل بين مشروع وآخر.

  1. EXT

    إضافة Chrome

    تتابع الصفحة وتثبّت العناصر وتلتقط الصور. ولا تسجّل أبدًا ما تكتبه في الحقول.

    Manifest V3
  2. SRV

    خادم محلي

    بلا أي اعتماديات. يقدّم الاستوديو، ويجمع كل حدث، ويكتب مجلد الجلسة.

    Node.js · 127.0.0.1
  3. UI

    الاستوديو

    وحدات ES بلا خطوة بناء: قائمة الملاحظات، وشاشة العرض، وشاشة المراجعة.

    plain JavaScript
  4. ASR

    التفريغ الصوتي

    نص موقّت كلمةً كلمة على GPU جهازك، ويجهز النموذج أثناء تسجيلك.

    faster-whisper · Python
  5. SKILL

    مهارة Claude Code

    تفتح الاستوديو، وتنتظر الإرسال، ثم تقرأ report.md والإطارات.

    /dictate

تُحفظ كل جلسة في مشروعك داخل .dictate/sessions/، ومعها report.md وsession.json والإطارات والنص المفرّغ وتسجيلك الصوتي. ويستثني المجلد نفسه من git.

أرِ Claude ما تقصده.

افتح مشروعًا في Claude Code، واكتب /dictate، وأشِر.
